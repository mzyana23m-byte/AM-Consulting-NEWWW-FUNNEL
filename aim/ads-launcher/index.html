0Connect Meta

Paste your Meta access token once. It's saved in this browser only and is only ever sent to Meta.

  1. Go to developers.facebook.com/tools/explorer (Graph API Explorer).
  2. Top right: pick your app under Meta App, and User Token.
  3. Under Permissions add: ads_management, ads_read, business_management, pages_show_list, pages_read_engagement, instagram_basic.
  4. Click Generate Access Token and approve the popup (select your ad account, Page and Instagram).
  5. To make it last 60 days: click the blue ⓘ next to the token → Open in Access Token Tool → Extend Access Token. Copy that one and paste it here.
